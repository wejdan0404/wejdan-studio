# استوديو وجدان

موقع تصاميم ثابت لمنشورات LinkedIn و X بهوية وجدان المالكي: ٢٢٠ تصميمًا في ١١ فئة (منها سلسلة / ثريد بصور ورمز QR)، بالعربية والإنجليزية، بالوضعين الفاتح والداكن.

## الاستخدام

1. افتحي الموقع، واختاري المنصة (LinkedIn أو X أو الاثنين) والفئة واللغة والوضع والنمط.
2. اكتبي محتوى الفئة في النموذج الجانبي ليظهر على كل تصاميمها، أو افتحي أي تصميم واضغطي على النص نفسه لتعديله.
3. التنسيق ثابت: يتغير الكلام فقط، ويصغُر الخط تلقائيًا ليبقى داخل المساحة، مع تنبيه لطيف إن صار صغيرًا جدًا أو اختفى نص ثانوي.
4. حمّلي التصميم صورة PNG بالمقاس الكامل، والكاروسيل ملف PDF.

تُحفظ تعديلات كل تصميم في متصفحك فقط (localStorage). زر «إرجاع نص هذا التصميم» يعيده إلى محتوى الفئة.

## الخطوط

الخطوط الأساسية تُحمَّل من Google Fonts. خط ثمانية لا يُرفق مع الموقع؛ إن كان مثبتًا على جهازك يظهر في العناوين تلقائيًا، وإن لم يكن ستظهر ملاحظة فيها رابط التحميل:
https://ask.thmanyah.com/hc/en-001/articles/45993930027281-thmanyah-Font-for-Everyone

## النشر على GitHub Pages

الملفات في جذر المستودع جاهزة كما هي (`index.html` و `assets/`). من إعدادات المستودع: Pages ← Deploy from a branch ← الفرع الرئيسي، المجلد `/ (root)`. لا يحتاج الموقع أي خادم ولا تسجيل دخول.

ملفا الشعار الرسميان (الحبري والأبيض) في `assets/brand/`.

# Wejdan Studio

A static design site for LinkedIn and X posts in Wejdan Almalki's identity: 220 designs across 11 categories (including threads with images and a QR code), Arabic and English, light and dark.

## Use

1. Pick the platform (LinkedIn, X or both), category, language, mode and style.
2. Write the category's content in the side form so it appears on every design in that category, or open any design and click its text to edit it in place.
3. The layout is fixed — only the words change. Text re-fits automatically to stay inside its space, with a gentle warning when it shrinks a lot or a secondary line has to hide.
4. Download a full-size PNG; carousels download as a PDF.

Per-design edits are stored only in your browser (localStorage). "Reset this design's text" returns it to the category content.

## Fonts

Base fonts load from Google Fonts. Thmanyah is never shipped: if it is installed on your device the headings use it; if not, the site shows a note with the download link above.

## Hosting on GitHub Pages

Everything is plain static files at the repo root (`index.html`, `assets/`). In the repo settings: Pages → Deploy from a branch → main, folder `/ (root)`. No server, no sign-in, no GitHub Actions.

The official W monogram files (ink and white) are in `assets/brand/`.

Third-party code: snapdom 3.3.3 and jsPDF 2.5.1, both MIT — licences in `assets/vendor/`.
